# E2E Test Scenario

## 1. Project Setup & Cover Image
- [ ] **Data Setup**: Ensure a user exists and is logged in.
- [ ] **Navigate**: Go to the Workspace Dashboard.
- [ ] **Action**: Click "New Project" (or use existing).
- [ ] **Verify**: Project Home loads.
- [ ] **Action**: Click "Set Art Style" (or "Edit Style" if already set).
- [ ] **Action**: Select a style and confirm.
- [ ] **Verify**: Toast/Notification appears: "Generating project cover image..."
- [ ] **Wait**: Wait for async generation to complete (simulated or real).
- [ ] **Verify**: Project Home header background updates with the new AI-generated image.
- [ ] **Navigate**: Go back to Workspace Dashboard.
- [ ] **Verify**: The project card in the list shows the new cover image.

## 2. Character Casting with AI
- [ ] **Navigate**: Go to Project Home.
- [ ] **Verify**: "Start Character Casting" nudge is visible (if style is set).
- [ ] **Action**: Click "Start Character Casting".
- [ ] **Verify**: Casting Wizard/Page opens.
- [ ] **Action**: Enter Character Name (e.g., "Hero").
- [ ] **Action**: Enter basic description (e.g., "A brave knight").
- [ ] **Action**: Click "Augment with AI".
- [ ] **Verify**: Description field updates with richer text generated by Gemini 2.5 Flash.
- [ ] **Action**: Click "Generate Character Sheet".
- [ ] **Verify**: Loading state/Notification: "Generating character sheet..."
- [ ] **Wait**: Wait for image generation.
- [ ] **Verify**: Generated image appears.
- [ ] **Check**: Verify image composition: Left half face, Right full body.
- [ ] **Action**: Save Character.
- [ ] **Verify**: Character saved and listed in the project.

## 3. Episode Creation & AI Assistance
- [ ] **Navigate**: Go to Project Home -> "Create Episode".
- [ ] **Action**: Click "Generate Ideas with AI".
- [ ] **Verify**: 3 options appear (generated by Gemini 2.5 Flash).
- [ ] **Action**: Select one idea.
- [ ] **Action**: (Optional) Edit the selected idea.
- [ ] **Action**: Click "Create Episode".
- [ ] **Action**: Set Cut Count (e.g., 4 cuts).
- [ ] **Action**: Click "Generate Script/Storyboard".
- [ ] **Verify**: List of 4 cuts appears with text descriptions (Gemini 3.0 Preview).
- [ ] **Action**: Review/Edit text for Cut 1.
- [ ] **Action**: Click "Generate Images" for the episode.
- [ ] **Verify**: Images start generating for each cut (Gemini 3.0 Image Preview).
- [ ] **Verify**: Images populate as they finish.

## 4. Episode Review (Mobile View)
- [ ] **Action**: Click "Review Episode" / "Mobile View".
- [ ] **Verify**: Mobile Mockup viewer opens.
- [ ] **Action**: Scroll down through the cuts.
- [ ] **Verify**: Images and text are displayed correctly in a webtoon format.
- [ ] **Action**: Close viewer.
